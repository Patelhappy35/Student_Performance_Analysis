# Student Performance Analysis Using Python

## 🎯Project Overview
This project focuses on analyzing student academic performance using Python. The analysis is performed on a dataset containing 5,000 student records.

The main objective is to understand student performance through statistical calculations, probability concepts, data visualization, and linear algebra.

## 📂Dataset Information
**Dataset Name:** `students_scores.csv`

**Total Records:** 5,000  
**Total Columns:** 7

### 📌Dataset Features
- Student_ID
- Age
- Math_Score
- Science_Score
- English_Score
- Hours_Studied
- Pass_Fail (0/1)

## 🛠️Technologies & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## 📚Project Tasks

### 1. Measures of Central Tendency & Dispersion
- Calculated Mean, Median, and Mode of Math Scores.
- Calculated Range, Variance, and Standard Deviation of Science Scores.

### 2. Probability Basics
- Calculated the probability of students passing.
- Created a Contingency Table between Pass_Fail and Hours_Studied > 5.
- Calculated Conditional Probability of passing for students studying more than 5 hours.

### 3. Distribution & Data Visualization
- Created a Histogram with Normal Distribution Curve for Math Scores.
- Calculated Skewness and Kurtosis for Science Scores.
- Created a Q-Q Plot for English Scores.

### 4. Linear Algebra
- Represented Math and Science scores of the first five students as vectors.
- Calculated Dot Product.
- Calculated L1 and L2 Norms of the Math Score vector.
- Calculated the Angle Between Two Vectors.

## Key Insights

1. Overall student pass percentage is **61.08%**.
2. Overall student fail percentage is **38.92%**.
3. Average Math Score is **68.18**.
4. Average Science Score is **67.67**.
5. Students studying more than 5 hours have a **73.48% pass rate**.
